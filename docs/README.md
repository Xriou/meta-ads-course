## 这本书是什么

这是一份从零基础到操盘手的系统化 Meta 广告学习资料。内容源自一条完整的苏格拉底式学习对话，经过提炼、事实分级与结构化重写而成：

- 每张卡片都有统一的骨架：**讲解 → 底层机制 → 实操清单 → 实战案例 → 常见错误 → 自测 → 掌握标准**
- 内容按信源强度标注：**【官方（Meta）】/【推理】/【实战】**，不混淆"官方说的"与"经验推断的"
- 案例聚焦 B2B 工业设备出海场景（已做泛化处理），但方法论通用
